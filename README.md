# Customer Retention — Credit Card Portfolio

Менеджер розничного кредитного портфеля видит рост оттока клиентов и хочет понять его причины, чтобы проактивно работать с клиентами из группы риска, прежде чем они уйдут.

## Состав проекта

- [`src/EDA_credit_card_churn.ipynb`](./src/EDA_credit_card_churn.ipynb) Jupyter-ноутбук: очистка данных, feature engineering (Age Group, Risk Segment), разбор бизнес-вопросов заказчика по сегментам, проверка значимости (chi-square)
- [`data/BankChurners.csv`](./data/BankChurners.csv) исходный датасет (Kaggle, [Credit Card Customers](https://www.kaggle.com/datasets/sakshigoyal7/credit-card-customers)).
- Дашборд: **Customer Retention Dashboard | Credit Card Portfolio** — tbd.

## Пайплайн

1. Загрузка данных (10 127 клиентов, 23 колонки).
2. Удаление служебных `Naive_Bayes_Classifier_*` колонок согласно предупреждению автора датасета на Kaggle.
3. Переименование полей на бизнес-язык (`Attrition_Flag` → `Customer Status`, `Total_Relationship_Count` → `Products Count` и т.д.), те же имена используются в PowerBI.
4. Проверка пропусков и дублей клиентов.
5. Feature engineering: `Is Churned`, `Age Group`, `Risk Segment` (составное правило на основе неактивности, числа продуктов и утилизации карты).
6. Разбор бизнес-вопросов по сегментам: возраст, доход, тип карты, число продуктов, неактивность, риск-сегмент, распределение утилизации.
7. Проверка статистической значимости найденных различий (критерий хи-квадрат).

## Ключевые находки

- Общий Churn Rate по базе **16,07%**.
- Клиенты 40–49 лет уходят чаще всего (**~16,9%**), 18–29 лет реже всего (**~8,7%**).
- Клиенты с 1–2 продуктами банка уходят почти в 2,5 раза чаще, чем клиенты с 4+ продуктами.
- Сегмент High Risk уходит в **~7 раз** чаще, чем Low Risk (37,6% против 5,2%).
- Все перечисленные различия статистически значимы (p-value < 0.05, критерий хи-квадрат).

## Практическая направленность

Такой пайплайн и дашборд можно использовать банку для приоритизации retention-кампаний: фокус ресурсов на клиентах с малым числом продуктов, низкой утилизацией карты и растущей неактивностью. Risk Segment позволяет заказчику выгружать список клиентов High Risk для точечной работы, не дожидаясь, пока они уйдут.

## Технологии

Python (pandas, numpy, matplotlib, scipy) для очистки, feature engineering и валидации гипотез, PowerBI для интерактивной визуализации и фильтров
